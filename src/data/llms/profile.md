### Agentic AI architecture

- **Knowledge layer:**
  - Process Knowledge Models (PKM): versioned, YAML-based descriptions of
    processes, equipment, parameters, limits and relationships
  - alignment with open semiconductor ontologies
  - triplestores such as GraphDB, Apache Jena Fuseki and Oxigraph
- **Orchestration layer:**
  - LangGraph / LangChain multi-agent StateGraphs
  - durable workflow orchestration
  - MCP (Model Context Protocol) tools
  - an agent marketplace architecture
- **Intelligence layer:**
  - EWMA, CUSUM, PCA and Hotelling's T²
  - ensemble ML with conformal prediction
  - ViT and ConvNeXt vision models, and HDBSCAN
  - Triton and MLflow
  - vector databases
- **Data layer:** Kafka, Flink, TimescaleDB, PostgreSQL and pgvector.
- **Control layer:**
  - human-in-the-loop gates
  - progressive autonomy: advise, recommend with approval, act within bounds,
    act and report
  - audit trails and rollback

### Views on agentic AI

1. From copilots to coworkers: real value comes when agents own bounded tasks end to end.
2. Domain grounding beats model size.
3. Autonomy is earned, not declared.
4. Humans move up the stack, from operating to supervising.
5. Agents need infrastructure, not just prompts.
6. Reuse is the multiplier.
7. Open standards matter: MCP, open ontologies and SEMI standards.

He describes agent proliferation in five stages: Pilot, Pattern, Platform,
Fabric, and Autonomous operations.
